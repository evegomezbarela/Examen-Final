# Examen-Final Habitacion de hotel
Este programa es una aplicacion de consola hecha en Java. Sirve para guardar habitaciones de un hotel, reservarlas y calcular cuanto cuesta hospedarse.

Archivos


*HabitacionHotel.java: la clase de la habitacion.

*Main.java: el menu del programa.

La habitacion tiene:

-Numero

-Precio por noche

-Capacidad de personas

-Si esta ocupada o no



Si se crea una habitacion por defecto, tiene el numero 101, cuesta 120000 por noche, es para 2 personas y esta libre.

Que puede hacer

*Reservar: revisa que la habitacion este libre y que quepan las personas. Si todo esta bien, la deja ocupada.

*Calcular hospedaje: multiplica el precio por las noches. Si son 5 noches o mas, se le quita el 10%.

Menu

1.Crear objeto por defecto

2.Crear objeto con parametros

3.Modificar atributos del objeto

4.Visualizar objetos registrados

5.Ejecutar metodo de comportamiento 1 (reservar)

6.Ejecutar metodo de comportamiento 2 (calcular hospedaje)

7.Salir


El menu se repite hasta que se elige la opcion 7. Se pueden guardar hasta 10 habitaciones.
